# Build plan

About 19.5 hours, over the original 14 by choice (review of 2026-09-30). The order follows dependencies. The model and prompt constants must be frozen before classification runs. The backfill command only stores Google News candidates, so it does not wait on those constants. Eval needs real articles, so collection comes before eval. The RSS backfill is the short run. Classification, once built, is the long one. The backfill starts before the dashboard is built. The design in `docs/ARCHITECTURE.md` and the ADRs stays whole even if a later task slips. A slip is recorded in the README, not by deleting the decision.

Tests are written with each task. The last test row closes the gap to 100%.

- D1, 2026-10-01: grilled with Itay. Field problems are returned, not thrown (coding standard updated). Custom dates are `YYYY-MM-DD` only. `published_at` has a CHECK for the `toISOString` shape. `subscriptions.email` is `COLLATE NOCASE`.
